# 참조 녹음 만들기

Ming은 참조 녹음의 목소리 결과 말투를 따라 해요. 참조가 결과를 거의 결정하니, 여기에 가장 신경 쓰세요.

## 조건

- **본인 목소리**이거나 녹음 주인에게 허락받은 목소리
- 길이 **10~15초** (실험: 13초). 한 사람만, 배경 음악·효과음 없이
- 평소 내가 쓰고 싶은 말투로 말한 구간. 내레이션용이면 내레이션 녹음에서 자르기
- 문장 중간에서 끊기지 않게, 숨 쉬는 쉼 지점에서 자르기
- 음량이 너무 작으면 올리기만 하고(실험: -31 LUFS → +10dB, 피크 -1.3 dBFS), 잡음 제거·EQ 같은 다른 처리는 하지 않기

## 파일 두 개

```text
ref/
├── my_voice.wav   # 위 조건의 녹음
└── my_voice.txt   # 그 구간에서 실제로 말한 그대로의 받아쓰기 (한 줄)
```

받아쓰기는 들리는 그대로 적어요. "어", "그" 같은 말버릇도 들어 있으면 적고, 숫자·영어도 말한 형태 그대로 적어요. 받아쓰기가 녹음과 다르면 결과가 흔들릴 수 있어요.

자르기와 변환 예시(ffmpeg):

```bash
# 원본 128.6초부터 13초 자르기, mono
ffmpeg -ss 128.6 -t 13 -i narration.wav -ac 1 ref/my_voice.wav
```

Ming이 내부에서 샘플레이트를 맞추므로 24kHz·44.1kHz·48kHz 모두 괜찮아요. 스테레오면 mono로 합쳐요.
